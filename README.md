# 📝 To-Do List Web Application : https://todolist83.netlify.app/

A simple and responsive **To-Do List** web application built using **HTML, CSS, and JavaScript**.  
It helps users manage daily tasks easily with a clean and user-friendly interface.

---

## 🚀 Features
- Add new tasks
- Delete tasks
- Simple and clean UI
- Responsive design
- Fast and lightweight

---

## 🛠️ Technologies Used
- **HTML** – Structure
- **CSS** – Styling
- **JavaScript** – Functionality and DOM manipulation

---

## 🎯 Purpose
This project was created to practice **JavaScript basics**, DOM manipulation, and front-end development concepts.
